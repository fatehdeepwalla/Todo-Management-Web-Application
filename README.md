# Todo Management Web Application

A secure Todo management web application built with **Spring Boot, Spring MVC, JSP, Spring Security, Spring Data JPA, and H2**.

The application supports user authentication, Todo CRUD operations, form validation, and database persistence using H2.

## Features

- User authentication with Spring Security
- In-memory user authentication
- Create Todo
- View Todos
- Update Todo
- Delete Todo
- Form validation
- Target date selection
- User-specific Todo management
- H2 database persistence
- JSP-based web interface
- Bootstrap-based styling

## Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA
- JSP
- JSTL
- H2 Database
- Hibernate
- Bootstrap
- Maven
